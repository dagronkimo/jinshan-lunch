# 🍱 金山街今天中午吃啥

新竹金山街＋附近的午餐轉盤，附簡易位置地圖。

👉 **線上版：https://dagronkimo.github.io/jinshan-lunch/**

## 收錄條件
- 中午有營業（排除只開晚上的店、居酒屋、串燒、燒肉、薑母鴨、酒吧、咖啡店）
- Google 價位 $～$$（約 NT$400 以內）
- Google 評論 ≥ 400 則、評分 ≥ 4.2 星
- 金山街一帶 19 間＋附近（關新路、光復路、關東路，約 1–1.3 km）15 間，共 34 間

## 功能
- 轉盤：可選「只轉今天中午有開」、「只要 $ 等級」、金山街一帶／附近
- 排名：評分 × 評論數的貝氏加權
- 地圖：全區／金山街放大，點選看店家、一鍵開 Google 地圖
- 取消勾選的店會記在自己的瀏覽器
